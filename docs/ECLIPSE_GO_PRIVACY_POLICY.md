# Política de Privacidade — EclipseGo

**Última atualização:** 13 de julho de 2026

Esta Política de Privacidade descreve como o aplicativo **EclipseGo** ("o aplicativo", "nós") trata as informações dos usuários.

## 1. Resumo

O EclipseGo é um aplicativo totalmente **offline**. Ele foi projetado para funcionar sem qualquer conexão com a internet: todos os dados de eclipses, cidades/localizações e os cálculos de visibilidade ficam armazenados diretamente no seu dispositivo. **O aplicativo não realiza chamadas de rede, não possui servidores próprios e não coleta, transmite ou compartilha dados pessoais com terceiros.**

## 2. Dados que o aplicativo utiliza

### 2.1 Localização do dispositivo (GPS)

O EclipseGo pode solicitar permissão de localização (`ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`) para a funcionalidade "Minha localização", que calcula automaticamente se um eclipse é visível a partir de onde você está.

- Essa permissão é **opcional**: caso não seja concedida, ou caso o GPS esteja indisponível, o aplicativo utiliza uma cidade padrão pré-definida para os cálculos.
- A localização obtida é usada **exclusivamente no próprio dispositivo**, em tempo real, apenas para os cálculos de visibilidade de eclipses.
- **A localização nunca é armazenada permanentemente, registrada em log, transmitida pela internet ou enviada a nós ou a terceiros.**

### 2.2 Dados de cidades e eclipses

O aplicativo inclui uma base de dados local de cidades e eventos de eclipses, empacotada junto com o aplicativo (arquivos internos). Essa base é usada apenas para permitir a busca de localizações e a exibição de eventos, e não envolve nenhuma coleta de dados do usuário.

### 2.3 Preferências e localização personalizada

Caso você selecione manualmente uma cidade ou localização personalizada ("Personalizada"), essa escolha é salva **apenas localmente no seu dispositivo**, para que o aplicativo lembre sua preferência entre uma sessão e outra. Esses dados não saem do aparelho.

## 3. Dados que o aplicativo NÃO coleta

O EclipseGo **não** coleta, armazena ou transmite:

- Nome, e-mail, telefone ou qualquer dado de identificação pessoal;
- Histórico de localização;
- Dados de uso, analytics ou telemetria;
- Identificadores de publicidade;
- Qualquer informação para fins de marketing ou de terceiros.

## 4. Permissões do aplicativo

| Permissão | Finalidade | Obrigatória? |
|---|---|---|
| Localização (fina/aproximada) | Calcular visibilidade de eclipses a partir da posição atual | Não — há fallback para cidade padrão |

O aplicativo **não solicita** acesso a câmera, microfone, contatos, armazenamento externo, internet ou qualquer outro recurso sensível.

## 5. Compartilhamento de dados com terceiros

Como o aplicativo funciona inteiramente offline e não realiza nenhuma comunicação de rede, **nenhum dado é compartilhado com terceiros, anunciantes, serviços de analytics ou qualquer outro serviço externo.**

## 6. Crianças

O EclipseGo não coleta dados pessoais de nenhum usuário, incluindo crianças, e pode ser utilizado por qualquer faixa etária sem riscos relacionados à privacidade.

## 7. Alterações nesta política

Caso esta política seja atualizada (por exemplo, se uma futura versão do aplicativo passar a incluir funcionalidades online), a data de "última atualização" no topo deste documento será revisada e as mudanças serão refletidas aqui.
