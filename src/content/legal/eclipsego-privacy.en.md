# Privacy Policy — EclipseGo

**Last updated:** July 13, 2026

This Privacy Policy describes how the **EclipseGo** application ("the app", "we") handles user information.

## 1. Summary

EclipseGo is a fully **offline** application. It is designed to work without any internet connection: all data on eclipses, cities/locations, and visibility calculations are stored directly on your device. **The application does not make network calls, does not have its own servers, and does not collect, transmit, or share personal data with third parties.**

## 2. Data Used by the Application

### 2.1 Device Location (GPS)

EclipseGo may request location permission (`ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`) for the "My Location" feature, which automatically calculates if an eclipse is visible from where you are.

- This permission is **optional**: if not granted, or if GPS is unavailable, the application uses a predefined default city for calculations.
- The obtained location is used **exclusively on the device itself**, in real time, only for eclipse visibility calculations.
- **The location is never permanently stored, logged, transmitted over the internet, or sent to us or third parties.**

### 2.2 Cities and Eclipses Data

The application includes a local database of cities and eclipse events, packaged with the application (internal files). This database is used only to allow location searching and event display, and does not involve any user data collection.

### 2.3 Preferences and Custom Location

If you manually select a city or custom location ("Custom"), this choice is saved **only locally on your device** so the application remembers your preference between sessions. This data does not leave the device.

## 3. Data the Application Does NOT Collect

EclipseGo **does not** collect, store, or transmit:

- Name, email, phone number, or any personally identifiable data;
- Location history;
- Usage data, analytics, or telemetry;
- Advertising identifiers;
- Any information for marketing or third-party purposes.

## 4. Application Permissions

| Permission | Purpose | Required? |
|---|---|---|
| Location (fine/approximate) | Calculate eclipse visibility from the current position | No — fallback to default city |

The application **does not request** access to camera, microphone, contacts, external storage, internet, or any other sensitive resource.

## 5. Sharing Data with Third Parties

Since the application works entirely offline and does not perform any network communication, **no data is shared with third parties, advertisers, analytics services, or any other external service.**

## 6. Children

EclipseGo does not collect personal data from any user, including children, and can be used by any age group without privacy-related risks.

## 7. Changes to This Policy

If this policy is updated (for example, if a future version of the application starts to include online features), the "last updated" date at the top of this document will be revised and changes will be reflected here.
